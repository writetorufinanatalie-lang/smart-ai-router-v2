PROCESSING LOCATION

What runs locally

Classification uses the local Ollama runtime and selected local model. Simple answers are generated locally. Whitelisted device commands are parsed and simulated in the backend’s in-memory registry.

CLOUD ROUTE

What could leave this machine

If a cloud provider and its configuration are present and a request is actually sent on the cloud route, the request text is passed to that provider. The current backend reports whether cloud configuration is present and whether each recent request was sent; configuration status alone is not a provider connectivity test.

PATTERN-BASED CHECK

What the Privacy Shield checks

The local Shield looks for common email-address, phone-number, and card-like number patterns before cloud handoff. It can miss unusual, obfuscated, split, or otherwise differently formatted values, and it does not identify every kind of sensitive information. A request with no recorded match is not proof that it contains no sensitive data.
